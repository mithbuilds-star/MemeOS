# MemeOS roadmap

## V1 — Core MemeOS (this repository's target)
- App shell, authentication, database, storage.
- Account and reference source management.
- Discovery job initiation.
- Meme creator and central library.
- Approval workflow and scheduler views.
- Publishing history, basic analytics and health.

## V1 completion work still required
- Apify dataset polling and schema adapter for the selected actor.
- Download media and run OCR.
- Text classification and automated BRAT asset pipeline.
- Assignment creation, parent graph UI and inheritance propagation.
- Per-account approval operations.
- Scheduling CRUD and persistent scheduled job runner.
- Meta OAuth, token lifecycle and Graph API photo publishing.
- Meta insights sync.
- Automated tests and live integration validation.

## V2 — Full automation
- MP4/Reels rendering.
- Official audio support if Meta makes it available for the intended publishing flow.
- Full autonomous discovery-to-approval/publishing pipeline.
- Robust job orchestration, retry/recovery and multi-account automation.

## V3 — Intelligence and optimization
- Advanced analytics.
- Content/source ranking.
- Posting-time optimization.
- Performance-driven discovery prioritization.
- Long-term trends and recommendations.
